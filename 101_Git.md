# Лабораторная работа № 1. Основы Git и совместной разработки на GitHub

## Цели работы

- Освоить базовые команды Git: `init`, `status`, `add`, `commit`, `log`, `show`.
- Научиться работать с ветками, выполнять `merge` и `rebase`.
- Освоить **fork-workflow** — внесение изменений через собственную копию репозитория.
- Научиться создавать **Pull Request (PR)**

## Необходимые ресурсы

- [Git Mastery](https://gitmastery.me/) — интерактивный тренажёр для изучения Git.

## Задание

### Часть 1. Пройти уроки Git Mastery

1. Откройте [Git Mastery](https://gitmastery.me/).
2. (Опционально) Пройдите все уроки уровня "Beginner": Introduction to Git, File Operations, Working with Branches, Remote Repositories.
3. Пройдите все уроки уровня "Advanced": Merging Branches, Git Workflows, Team Collaboration, Undoing Commits, Git Stash.
4. **Сделайте скриншот результатов**, на котором видно, что требуемые уроки пройдены.

### Часть 2. Создание отчёта и Pull Request в репозиторий

1. Откройте Practice101: <https://github.com/EngeneeringMindset2026/Practice101> и сделайте fork репозитория кнопкой **Fork**.
2. Клонируйте свой форк на компьютер командой git clone.
3. Создайте отдельную ветку для лабораторной работы:

   ```bash
   git checkout -b lab1/<username>
   ```

4. Создайте каталог `ФамилияИО/` и добавьте в него:

   - `ФамилияИО.md` — краткий отчёт, список пройденных тем и 2–3 предложения о том, что вы освоили;
   - `gitmastery.png` (или несколько изображений) — скриншот(ы) пройденных уроков;

   **Пример структуры:**

   ```text
   /
   └── ИвановИИ/
       ├── ИвановИИ.md
       ├── gitmastery.png
   ```

5. Проверьте изменения и создайте коммит (команды git add, git commit)

6. Отправьте ветку в свой форк с помощью команды git push

7. На GitHub создайте **Pull Request** из ветки своего форка в **основную ветку исходного репозитория Practice101**.

## Результат работы

**Сдаётся ссылка на Pull Request** в репозитории Practice101: <https://github.com/EngeneeringMindset2026/Practice101>.

Pull Request должен содержать:

- `ФамилияИО.md` с кратким отчётом;
- скриншоты, подтверждающие прохождение уроков на Git Mastery;
- понятное название и описание PR.

Принятый Pull Request означает сданную работу.
